{# 표 공용 도구 — 페이지 버튼 + 머리글 클릭 정렬. 인시던트 티켓 표와 최근 이벤트 표가 똑같은 동작을 하므로 함수를 한 곳에 두고 두 표가 같이 쓴다. 표마다 '지금 몇 페이지·어떤 컬럼·어느 방향'을 담은 상태 객체(state)를 하나씩 들고, 그 객체를 함수에 넘기는 방식이다. 쓰는 법 (표 하나당): const st = newTableState(); // {page, per_page, sort, order} bindSortHeaders(theadEl, st, loadFn); // 머리글 클릭 → 정렬 토글 ... fetch('/api/...?' + tableQuery(st, {filter})) // 쿼리스트링 만들기 paintSortHeaders(theadEl, st); // ▲▼ 표시 갱신 renderPager(pagerEl, body, (p) => { st.page = p; loadFn(); }); 정렬 가능한 컬럼은 처럼 표시한다. data-sort 가 없는 머리글(사유·제목 등)은 눌러도 반응하지 않는다 — 서버가 허용하지 않는 컬럼이라 눌리면 400 이 되기 때문이다. #}
